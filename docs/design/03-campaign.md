## 1. 뼈대 [확정]

- **연속 전투 캠페인.** 전투를 이어서 싸우고, 전투 사이의 **정비**에서 병력·돈·승급·편성을 관리한다. 잃은 병력과 쓴 돈이 다음 전투로 이어진다.
- **첫 캠페인: 황건적 3연전.** 유관장(유비, 관우, 장비)이 황건적 쉬움 → 보통 → 어려움과 차례로 싸운다 (기존 편성 `shuStart`, `yellowEasy`, `yellowNormal`, `yellowHard`).
- **초반 1~3전은 유관장만** 싸운다 (v0.3에서 바꿈. 처음에는 1전 뒤 조운, 2전 뒤 황충이 합류했다). 합류는 전투마다 정할 수 있다 (`battles[].joins`).
- **패배하면 같은 전투에 다시 도전**한다. 잃은 병력과 쓴 돈은 그대로 남고 보상은 없다. 정비하고 다시 싸운다.
- **돈과 병력은 원작식 보충/증원/해고**로 관리한다.
- **군단 레벨이 최대 병력의 상한**을 정하고, 실제 정원은 **증원**으로 상한까지 늘린다.
- **승급은 군단 레벨 조건.** 시작 Lv1, 1차 승급 Lv5, 2차 승급 Lv10 (레벨 값은 [임시]).

## 2. 군단의 상태

캠페인에서 장수(군단) 하나는 다음 값을 가진다.

| 값 | 뜻 |
|---|---|
| 레벨, 경험치 | 전투로 경험치를 얻어 오른다 |
| 병종 | 지금 병종 (승급 트리의 위치) |
| **상한** | 레벨로 정해지는 최대 병력 = 250 + 50 × 병력 배율 × (레벨 − 1) (전투 규칙과 같은 공식) |
| **정원** | 돈을 내고 확보한 인원. 상한을 넘을 수 없다 |
| **병력** | 지금 병사 수. 정원을 넘을 수 없다. 전투에서 줄어든다 |

- 전투는 **지금 병력**으로 시작하고, 전투에서의 최대 병력은 **정원**이다 [기본값]. 병력 보정(비율 구간식)은 정원 대비 비율로 센다.
- 병력이 0인 군단은 출전할 수 없다 (보충해야 한다) [기본값]. 전멸해도 장수를 잃지는 않는다.

## 3. 정비에서 하는 일

| 행동 | 효과 | 비용 |
|---|---|---|
| **보충** | 병력을 정원까지 채운다 (원하는 만큼) | 1명당 병종의 보충 단가 (`unitType.recruit.replenish`) |
| **증원** | 정원을 늘린다 (상한까지). 늘린 만큼 병력도 함께 는다 [기본값] | 1명당 병종의 증원 단가 (`recruit.reinforce`) |
| **해고** | 정원과 병력을 줄인다 | 1명당 해고 단가만큼 **돌려받는다** (`recruit.dismiss`) |
| **승급** | 레벨 조건을 넘은 군단이 승급 트리의 다음 병종 중 하나를 고른다 | 없음 [기본값] |
| **편성** | 출전할 군단과 자리(전열 1·2·3, 후열 4·5·6)를 고른다 | 없음 |

- 단가는 병종 데이터에 이미 있다 (원작의 절반 [기본값]). 예: 보병 증원 24, 보충 2 / 방패병 증원 20, 보충 1 / 기병 증원 36, 보충 4.
- 승급하면 병력 배율이 바뀌어 상한이 달라질 수 있다. 정원이 새 상한보다 크면 상한으로 줄이고 그만큼 해고 단가로 돌려준다 [기본값].
- 승급한 병종의 단가는 그 병종의 값을 쓴다 (값이 없으면 뿌리 병종의 값) [기본값].

## 4. 전투 뒤

| 항목 | 규칙 | 값 [임시] |
|---|---|---|
| 승리 보상 (돈) | 전투마다 정해진 금액 | 1전 1000, 2전 1300, 3전 1600 |
| 경험치 | 출전한 군단마다: 승리 기본 + 처치 1당 추가 (패배는 적게) | 승리 120, 패배 40, 처치 1당 20 |
| 레벨업 | 경험치가 쌓이면 레벨이 오르고 상한이 는다 (정원은 그대로, 증원해야 는다) | 레벨당 필요 경험치 100 |
| 병력 | 전투가 끝난 병력 그대로 다음 정비로 간다 | |

- 시작 자금 [임시] 500.
- 합류한 장수는 **파티 평균 레벨**(반올림)로 들어오고, 정원과 병력은 그 레벨의 상한으로 가득 찬 상태다 (v0.6).
- 유관장은 Lv1, 0차 병종(편성 `shuStart`의 병종), 정원과 병력은 Lv1 상한으로 가득 찬 상태로 시작한다 (v0.6. v0.4~v0.5에는 병종별 시작 병력이 있었다).
- **포획** (v0.4): 이기면 살아남은 군단마다 자기가 줄인 적 병력 × 포획 비율([임시] 5%)만큼 정원과 병력이 는다 (레벨 상한까지). 지면 없다.
- 적의 레벨은 전투마다 정한다 [임시]: 1전 Lv1, 2전 Lv3, 3전 Lv5. 적 군단은 레벨 상한으로 가득 찬 병력이고, 전투마다 "적 병력"(명)을 정하면 그 값이다 (레벨 상한까지).

## 5. 구현 방향 [기본값]

- **캠페인 규칙은 순수 TypeScript**(React/PixiJS/DOM 없음)로 만든다. 상태를 받아 새 상태를 돌려주는 함수들: 보충, 증원, 해고, 승급, 편성, 전투 결과 반영(보상, 경험치, 레벨업, 합류).
  위치: `packages/battle-engine/src/campaign/` (같은 엔진 패키지 안의 하위 폴더. 새 패키지를 만들지 않는다).
- 전투 입력은 기존 `BattleInput`이고 편성 항목에 레벨과 병력(정원·현재 병력)을 넘길 수 있게 넓힌다.
- 캠페인 데이터(전투 순서, 적 편성과 레벨, 보상, 합류, 시작 자금, 경험치 값)는 `packages/game-data/data/campaign.json`에 둔다. **Balance Lab의 "캠페인" 탭**에서 고치고, 그 자리에서 자동 정비 캠페인을 여러 번 돌려 결과(전투별 도달·한 번에 이김·평균 도전·남은 돈, 끝난 뒤 레벨, 한 번 따라가 보기)를 본 뒤 "파일에 저장"한다.
- 확인: 단위 테스트 + CLI로 "AI가 정비를 자동으로 하며 3연전을 끝까지 돌리는" 시뮬레이션 (돈이 모자라거나 남는지, 레벨이 몇까지 오르는지 본다).
- 정비 화면은 디자인 담당에게 TODO의 "담당 간 요청"으로 넘긴다 (필요한 상태와 함수 목록을 함께).

## 6. 미정


- 승급에 돈이나 조건(특정 전투 승리)을 더할지.
- 장수가 전투에서 전멸했을 때 벌칙(경험치 없음 등)을 둘지.
- 캠페인을 저장/불러오기하는 방식 (게임 화면 쪽과 함께 정한다).
