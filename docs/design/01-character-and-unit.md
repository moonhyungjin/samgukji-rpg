## 2. 캐릭터 구조

```text
Character
├─ id, 이름, 세력
├─ unitType        1차 병종 (고정)
├─ 스탯 8종         공격 / 방어 / 지력 / 속도 / 행동력 / 외교 / 내정 / 매력   (0~10)
├─ (AP)            전투 총 AP = 병종 기본 AP + 행동력 ÷ 2 (올림). 별도 필드 없음
├─ 군단 레벨, 경험치   (군단전용)
├─ 개별 레벨, 상한      (일기토용, 보류)
├─ 필살기(유니크만) / 특성(0~2)
└─ 장비 1
```

정적 데이터(`CharacterData`)와 전투 중 상태(`CharacterState`)는 분리한다.

`CharacterState` 후보: `troops/maxTroops`, `ap`, `guardRate`(방패병), `statusEffects[]`, `statMods[]`, `slot`(진영/열/행).

예시 (임시 수치):

```text
관우   공 9 / 방 7 / 지 6 / 속 6   병종: 기병
장비   공 8 / 방 9 / 지 4 / 속 5   병종: 방패병 (가드를 쓴다)
```

### 스탯 정의

| 스탯 | 용도 |
|---|---|
| 공격 | 보병/기병/궁병의 피해량 |
| 방어 | 물리 피해 감소 |
| 지력 | 책략/도술 피해량, 회복량, 상태이상 적용 확률과 저항 |
| 속도 | 라운드 내 행동 순서 |
| 외교, 내정 | 전략용. 군단전에서는 사용하지 않음 (필드만 정의) |
| 매력 | 전략용(영입 등). 군단전 사용 여부 [미정] |

- 군단전 능력은 캐릭터 스탯으로 결정된다. **군단 레벨은 스탯을 올리지 않는다.** [확정]
- 스탯은 `statCurve`(변환 테이블)를 통해 전투 수치로 바뀐다. 곡선은 Balance Lab에서 수정한다.
- 아이템 보정에는 하드캡을 둔다 [임시 15].

## 3. 군단 레벨 · 병력

```text
최대 병력 = 300 + 50 × (군단 레벨 − 1)      (Lv1 시작 가정) [확정]
```

| 레벨 | 최대 병력 | 비고 |
|---|---|---|
| 1 | 300 | |
| 15 | 1,000 | 1차 승급 |
| 30 | 1,750 | 2차 승급 후보 |

- 경험치: 전투 참가 기본 경험치 + 적 레벨 차이 보정 + 승리 보너스. 전투 횟수 방식과의 비교는 Lab에서 가능하게 열어 둔다.
- 레벨 상한은 임시 30. 2차 승급은 **데이터 슬롯만 두고 구현하지 않는다.**

### 병력과 피해량의 관계

원칙: **병력이 많을수록 더 많은 피해를 준다. 병력이 줄면 공격력이 높아도 피해가 작아진다.** [확정]

| 안 | 내용 |
|---|---|
| A | 현재 병력 / 최대 병력 비율만 반영 |
| B | 절대 병력 수 반영 |
| C | 하한/상한이 있는 혼합 곡선 (**채택**, 아래 공식) |

- 채택 공식 (구현 완료, 수치는 모두 [임시]이며 Lab에서 조정):
  ```text
  피해 = 공격 스탯 × attackScale(47) × 스킬 계수
         × 특성 보정 × 병력 보정(공격자)        ← 사기는 피해에 영향 없음 (기본값 0)
         ÷ (1 + 방어 × 0.1)            ← 책략은 방어 대신 대상의 지력으로 경감
  병력 보정 = clamp(현재 병력 / 1000, 0.3, 1.75)
  반격 피해 = 반격자의 일반공격 피해 × 0.5
  ```
- 병력 기준값 1000은 Lv15 최대 병력이다. Lv30(1,750)이면 보정이 상한 1.75에 닿는다.
- 보정 하한 0.3은 병력이 거의 남지 않은 군단도 일정 피해를 주게 하는 눈덩이 완화 장치다.

### 병종별 병력 배율 (실험 중)

- 같은 징병 비용으로 모이는 병력은 병종마다 다르게 할 수 있다 (예: 보병 500원 → 500명, 풍수사 500원 → 250명). `troopScale`(기본 1)이 군단 레벨로 정해진 최대 병력에 곱해진다.
- **현재 값 [확정]**: 풍수사 **0.6**, 책사 **0.8**, 기병 **0.8**, 도사 **0.8**, 궁병 **0.9** (병력이 비싼 병종), 보병/방패병 1. 이유: 풍수사의 치유가 상대에게 준 피해보다 많이 채우기 때문이다. 병력 배율은 치유량을 줄이지 않는다 (`heal.useTroopFactor`를 켜야 치유량도 병력에 비례한다). 지금 캐릭터 중에 풍수사는 없다 (곽가를 도사로 바꿨다).
- 병력이 적으면 공격이 약해지고(병력 보정) 더 빨리 쓰러진다. 치유량에도 병력 보정을 곱할지는 `heal.useTroopFactor`로 고른다 (기본 꺼짐).
- 시뮬레이션: 풍수사 0.5는 **너무 강하게 약해진다** (승률 61% → 26%, 생존 거의 0%). 균형점은 0.93~0.95 부근(승률 약 50%)이고 변화가 급격하다. 병력 배율이 다른 병종이 있으면 "병력이 가장 적은 적" AI가 그 병종을 항상 먼저 노리는 AI 편향이 생긴다 (루트 README 참고).
- 위험: 병력이 줄면 피해도 줄어 먼저 밀린 쪽이 더 불리해지는 **눈덩이 효과**가 생긴다. 하한으로 제어하고 역전 승률을 측정한다.

## 4. 병종 (6계열 × 2갈래 승급 = 18종)

| 계열 | 배치 | 공격 기준 | 타겟 규칙 | 일반공격 | 승급 A | 승급 B |
|---|---|---|---|---|---|---|
| 보병 | 전열 | 공격 | 전열 우선 | 공격(단일) → 공격2 | 창병 (대기병 특성) | [미정] |
| 방패병 | 전열 | 공격 | 전열 우선 | 공격(단일) + **가드** → 공격2 + 가드 강화 | [미정] | [미정] |
| 기병 | 전열 | 공격 | **전열 우선** (일단) | 돌격 → 돌격2 | 중기병 (화력) | 경기병 (기동, 후열 저격은 여기서 다시 정한다) |
| 궁병 | 후열 | 공격 | 전열 무시 | 화살 공격 → 화살 공격2 | 장궁병 (단일) | 노병 (관통) |
| 책사 | 후열 | 지력 | 책략 | 책략 → 책략2 | 군사 (광역) | 참모 (단일 고화력) |
| 도사 | 후열 | 지력 | 스킬별 | 독연 → 독연2 | (미정) | (미정) |
| 풍수사 | 후열 | 지력 | 아군 대상 | 치유 → 치유2 | AP 회복형 | 강화형 (스탯 상승 + 상태회복) |

- 승급 병종 이름은 임시다. 승급 조건은 **군단 레벨 15**.
- 표의 배치는 **시작 편성 규칙**이다. 전열이 전멸하면 후열이 전열이 된다 (`02-battle-rules.md` 1장).
- 일반공격은 병종이 정의하고, 승급하면 상위 버전으로 교체된다 (돌격 → 돌격2). [확정]
- 병종 데이터에 `factionRestriction`을 미리 둔다 (오나라 전용 수군 대비).
- 특수 병종(무희, 무도가, 적병)은 이번 범위에서 제외, 수군은 오나라 전용으로 다음 라운드. [확정]

### 병종 특성 (상성표 대신)

계열 간 상성표(보병 > 기병 > 궁병 > 보병)는 **두지 않는다.** [확정] 병종의 차이는 "병종이 가진 특성과 효과"로 만든다.

- 특성은 조건부 피해 보정이다. **주는 피해**(내가 공격할 때)와 **받는 피해**(내가 맞을 때)가 있고, 상대의 계열/열 조건에 맞으면 배율이 곱해진다. 조건을 비우면 모든 상대에게 적용된다.
- 예: 창병 → 기병 피해 ×1.25 (주는 피해), 궁병이 근접(보병/기병)에게 맞으면 ×1.3 (받는 피해). 이 두 예시는 데이터에 있지만 아직 어떤 병종에도 붙어 있지 않다. [임시]
- 지력 계열은 책략 피해를 **지력으로 저항**한다.
- 구현: `TraitData`(`kind`, `versus.families/rows`, `multiplier`)와 병종의 `traitIds`. Balance Lab에서 특성을 만들고 병종에 붙여 실험할 수 있다.
- **궁병 생존율 40%** (허용 ±10%p, 20%에서 변경)를 첫 목표 지표로 삼는다. [확정]
  - **당분간 병종에 특성을 붙이지 않고 순수 스탯 싸움으로 간다.** [확정] 기본 대상 선택 AI는 "예상 피해가 큰 적"이다. [확정]
  - 이 조건에서 궁병 생존율은 약 65%다. 참고로 궁병에 "근접에 취약 ×1.3"을 붙이면 18%까지 내려간다 (루트 README 참고).
  - 즉 "후열이 얼마나 맞는가"는 병종 수치보다 **타겟 선택 규칙**이 좌우한다. 실제 게임에서 플레이어의 선택이 이 역할을 한다.

### 가드 (방패병이 처음부터 쓴다)

- **보병(1차)이 처음부터 가드를 쓴다.** [확정] 같은 열 아군을 대신 맞아줄 확률을 쌓는 특수행동이다. 방패병(승급 B)은 가드를 강화하는 방향으로 다시 정한다. [미정]
- 수치: 시작 50%p, 가드 커맨드 +70%p (AP 1), 막을 때마다 −40%p (AP 소모 없음). 광역/관통/책략은 막지 못한다. 병종 데이터의 `guard: { start, gain, decay }`로 정의하고, 다른 병종에도 Lab에서 켤 수 있다.
- 규칙 전체는 `02-battle-rules.md` 4장 참고. 핵심은 **막기만 하거나 공격만 해야 한다**는 선택이다.
- 기병이 일단 전열만 공격하게 되면서, 전열의 가드가 실제로 작동할 기회가 생긴다 (기본 AI는 방어가 낮은 후열을 노리기 때문에 이전에는 전열이 거의 맞지 않았다).

## 5. 지력 계열 3종의 커맨드

### 책사 — 속성 책략 딜

커맨드는 **책략 → 책략2**로 단순화한다. [확정] 책략의 실제 효과는 `BattleContext`(날씨/전장 상태)에 따라 달라진다.

| 조건 | 효과 | 상태 |
|---|---|---|
| 기본 (맑음) | **화계**: 피해 + 화상 확률 | |
| 비 | **수계**: 피해 + 젖음 확률 | |
| 산악/절벽 지형 | **낙석**: 큰 피해 | |

- 우선순위는 지형 > 날씨 > 기본. 조건 구성과 수치는 [임시].
- 승급은 책략2의 분기 버전이다. 군사는 광역, 참모는 단일 고화력.
- 프로토타입 범위: 날씨 2~3종, 지형 없음으로 시작.
- 책략은 가드를 무시하고 상태이상까지 붙기 때문에 **피해 계수를 물리 일반공격보다 낮게** 둔다. [확정] 수치는 [임시].
- 주의: 전투 중 날씨가 고정이면 책사는 사실상 한 가지 책략만 쓴다. 다양성은 전투 시작 전 조건에 달려 있다. Lab에서 날씨별 책사 승률을 본다.

### 도사 — 상태이상

- 커맨드는 **독연 + 대기**만 가진다. [확정] (독연은 독 계열 일반공격으로 해석했다. 이름의 뜻이 다르면 수정)
- **혼란**과 **낙뢰**는 이번 범위에서 **제외**한다. 상위 클래스나 필살기로 되살릴지는 나중에 정한다. [확정]
- 승급 A/B의 방향은 [미정]. 승급하면 일반공격이 독연2로 교체되는 것만 정해져 있다. 후보: 광역 독 / 고농도 단일 독.
- 영향: 책사 수계(젖음) → 낙뢰 콤보는 **범위에서 사라진다.** 책사 + 도사의 시너지는 **화계(화상) + 독의 지속 피해 공존**이 담당한다.

### 책사/도사의 버프 (구현 완료) [확정]

- 책사 **독려**: 아군 하나의 **공격/방어/지력/속도 중 무작위 1~3가지(가짓수도 무작위)를 +1** (전투 끝까지). 운이 좋으면 세 가지가 한꺼번에 오른다. 한 아군에게 1회.
- 도사 **결계**: 아군 하나가 **다음 피해 1회를 무시**한다 (전국란스의 음양사 느낌). 반격 피해에도 적용된다. 한 아군에게 1회.
- 둘 다 AP 1. 병력이 없어도 아군을 도울 수 있게 하려는 설계다 (병력 회복을 대신한다).
- 이름(독려/결계), +1이라는 폭, 가짓수 범위, 피해 무시 횟수는 [임시]. 스킬 데이터(`buff`)이므로 Lab에서 조정한다.
- AI는 쓸 대상이 남아 있으면 공격보다 먼저 쓴다. 스탯 버프는 주력 공격 스탯(공격 또는 지력)이 가장 높은 아군에게, 결계는 전열(방어가 낮은 순)부터. [기본값]

### 풍수사 — 지원

- 1차 커맨드: **치유**(병사 회복) + 대기. [확정]
- **승급 A (AP 회복형)**: 치유2 + AP 회복. [확정]
  - 임시 수치: 대상 AP +1, 시전자 AP 1 소모, 대상의 최대 AP를 넘지 못함. 총량이 늘지 않고 **풍수사의 AP를 핵심 유닛(필살기 보유자 등)에게 옮기는 효과**가 된다. +2로 올리면 순증이 생긴다. [임시]
- **승급 B (강화형)**: 치유2 + **스탯 상승 버프** + **상태회복**. [확정] 상승 스탯의 종류와 폭은 [미정].
- 턴 당기기는 폐기한다. [확정]

## 6. 상태이상 규칙

### 종류

| 상태 | 효과 | 처리 시점 | 부여 방식 |
|---|---|---|---|
| 화상 | 소량 피해 | 라운드 시작 | 확률 |
| 젖음 | **속도 감소** (라운드 내 행동 순서가 뒤로 밀림) [확정] | 지속 동안 상시 | 확률 |
| 독 | 즉시 소피해 + 중간 피해 | 라운드 종료 | 스킬 적용 시 확정 |
| ~~혼란~~ | (보류) 같은 열 아군 1명을 소피해로 공격 | 대상의 행동을 대체 | 도사에서 제외, 보류 |
| 낙석 | 즉발 큰 피해 (책략의 산악 지형 효과) | 즉시 | 스킬 |
| ~~낙뢰~~ | (보류) 젖음이면 큰 피해, 아니면 중간 피해 | 즉시 | 도사에서 제외, 보류 |

- 젖음은 순서만 바꾸는 효과라 **단독 가치가 작다.** 낙뢰가 보류된 현재는 수계(책략)의 부가 효과 정도의 역할이다.
- 보류된 낙뢰의 `대상 상태 조건 → 배율` 구조는 데이터 필드로만 남겨 둔다. 이후 연계 효과를 추가할 때 쓸 수 있다.

### 공통 처리 기준

1. **틱과 지속시간은 라운드 기준**이다. AP가 0이어도 적용된다. [기본값] (이전 v0.2의 "대상의 행동 횟수 기준"은 AP 총량 모델과 충돌해 폐기)
2. **확률 판정**: 시드 기반 PRNG. 적용 확률은 `스킬 기본 확률 + (시전자 지력 vs 대상 지력)` 보정. 보정식은 [미정].
3. **지속 피해**: 부여 시점의 시전자 지력으로 스냅샷한다. [기본값]
4. **중복**: 같은 상태를 다시 걸면 갱신(스택 아님). [기본값]
5. **혼란 엣지 케이스**: 같은 열에 다른 아군이 없으면 해당 행동을 상실한다. [확정] (혼란이 보류 중이라 현재는 미사용)

### 상태별 상호작용

| 조합 | 규칙 |
|---|---|
| 화상 + 독 | **공존** [확정] |
| 화상 ↔ 젖음 | **상쇄** (서로 지움) [확정]. 둘 다 소멸 가정. 대안: 새 상태가 기존 상태를 교체 [미정] |
| 책사 상태 + 도사 상태 | **중첩 가능** [확정] (현재 구성에서는 화상 + 독) |
| 책사 상태 + 책사 상태 | **시너지 작음** [확정] |

구현 방향: 상태 데이터에 `exclusiveWith`, `stackRule`(`refresh` / `coexist`), `sourceFamily`를 둔다. 출처 계열이 다르면 공존, 같으면 갱신으로 처리한다.

## 7. Balance Lab에 미치는 영향

- 군단 레벨은 Lab의 **기본 입력**이다(레벨 슬라이더). 병종/특성/레벨/스킬/정책을 각각 따로 실험할 수 있는 화면으로 나눈다.
- 확률 요소가 있어 분산이 크다. 시드 고정 재현과 충분한 반복 횟수가 필수다.
- 우선 검증 순서: **1차 병종 6종 → 특성/병력 공식 → 가드와 사기 → 상태이상 콤보 → 승급 12종.**
- 감시할 이상 징후: 눈덩이 효과, 책사 화상 + 도사 독의 중첩 피해, DoT 누적 폭주, 풍수사 AP 회복의 과잉, 가드 누적 과다.
