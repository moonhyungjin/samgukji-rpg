# 관우·공용 기병 아트 검토 v1

2026-10-07 내장 `image_gen`으로 제작한 첫 기마 시안. 2026-10-08 코드 대조: 관우와 공용 기병은 런타임에 116px 임시 기준으로 연결되어 있다. 게임 데이터는 변경하지 않는다. 외형 최종 마감과 관우 스탠딩은 `../WORKFLOW.md` 방침에 따라 보류한다.

## 열기

`preview.html`을 브라우저에서 연다. 파일을 직접 열어도 동작한다.

- 보병과 같은 지면에서 크기 비교: 유비 86px, 관우 108/116/124px.
- 공용 기병은 장수 대비 68/86 배율. 기존 병사 3명 오프셋과 96px 행 간격을 적용한 6대6 배치 검토.
- 좌우 반전, 밝음/어두움 배경, 지면 기준선을 제공한다.
- 기마 크기의 기준은 머리~발굽이다. 무기 끝과 두건 장식은 제외한다. 수동 기준점이므로 후속 자세에서는 재검토한다.

## 파일

| 파일 | 내용 |
|---|---|
| `sprites/guan-yu-mounted-v1.png` | 관우 + 적갈색 말 + 언월도, 오른쪽 방향 |
| `sprites/shu-cavalry-mounted-v1.png` | 공용 기병 + 갈색 말 + 창, 오른쪽 방향 |
| `prompts.json` | 내장 생성 도구의 최종 프롬프트 |
| `preview.html` | 독립 비교 페이지 및 원본 기준점 |

두 원본은 1536×1024 PNG이며 각각 약 1.92MB / 1.79MB다. 생성 파일을 재가공하지 않고 보존했다. 알파 채널은 있고 배경은 투명하다. 내부 알파는 완전한 255보다 약간 낮은 값(관우 표본의 주된 값 253)이므로 최종 런타임 텍스처 제작 시 확인한다.

## 결정과 검토 항목

- [확정, 기존 합의] 일반 등신대 만화체, 절제된 셀 채색, 기본 자세 한 장, 고유 장수와 공용 병사를 분리한다.
- [기본값, 구현 해석] 관우의 녹색 전포·긴 수염·언월도·적갈색 말. 일반 기병의 투구·창·갈색 말. 기존 유비/보병을 화풍 참조로 사용했다.
- [미정] 최종 기마 표시 크기. 비교 페이지의 기본 116px는 검토용이며 승인된 규격이 아니다. 기존 보병 크기는 바꾸지 않았다.
- [미정] 관우·공용 기병 외형의 채택 여부. 일반 기병 말 색과 갑옷 장식도 함께 검토한다.
- 관우 대화 스탠딩과 얼굴 카드용 원본은 아직 없다. 전투 그림에서 임의의 얼굴 카드를 만들어 확정하지 않는다.
- 실행용은 `apps/game/public/art/battle/`에 연결되어 있고 관우가 기병으로 출전할 때만 로드한다. 해상도/용량 최적화는 후속 작업이다.

## 검증

2026-10-08: 실제 6대6 공격측/방어측 기병 로딩 및 기존 검토 페이지 포함 브라우저 검사 41개 통과. 캡처는 `out/e2e-cavalry-rough/cavalry-runtime-attacker.png`, `cavalry-runtime-defender.png`. 좌우 반전과 화면 내 표시를 확인했다. 116px에서는 위쪽 군단 이름과 기병 실루엣이 가까워 일부 가림이 보인다. 러프 단계에서는 크기를 확정하지 않고, 병종 그림이 더 채워질 때 이름표/행 간격을 함께 조정한다. 새 이미지 생성은 하지 않았다.

검토 페이지를 포함한 브라우저 검증은 다음 환경 변수로 실행한다 (게임 개발 서버 필요).

```powershell
$env:ART_REVIEW_PATH='docs/art/cavalry/preview.html'
npm.cmd run e2e
```

기본 게임 검사에 이미지 로딩, 두 크기 변경, 반전/배경, 모바일 가로 넘침 검사 5개를 추가한다. 검토 캡처는 `E2E_OUT` 아래 `cavalry-review-*.png`에 저장된다.
