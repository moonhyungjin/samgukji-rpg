# 첫 전투 아트 묶음

상태: 시각 검토용 v2. 전투 표시 규격과 유비 대화용 스탠딩 추가. 실제 게임의 아트 시험 전투에 연결됨. 현재 연결 상태는 `../battle-integration.md`를 따른다.

## 합의된 방향

- UI는 첫 시안의 먹색/짙은 녹색 패널과 고풍스러운 금색 테두리.
- 장수, 병사, 초상화는 세 번째 시안의 일반 등신대 만화체. SD 제외.
- 아군 보병과 황건 보병은 별도 디자인으로 제작.
- 최초에는 기본 자세 한 장. 전진/복귀, 점멸, 흔들림, 참격/화살/가드 효과로 연출.
- 일반 장수는 공용 지휘관형, 네임드는 고유 외형. 군단은 장수 1명과 반복 배치한 병사들로 표현.

## 파일

- `preview-v2.html`: 공통 축척/발 기준선, 대화 스탠딩, 동일 원본에서 표시하는 얼굴 카드. 현재 검토용 진입점.
- `asset-layout.js`: 기존 전투 이미지 4종의 원본 머리/지면 좌표와 논리 캔버스 규격.

- `standing-prompt.json`: 스탠딩 제작에 사용한 내장 image_gen 프롬프트.

- `sprites/liu-bei-idle-v1.png`: 유비, 오른쪽을 향함.

## 검토 기준

### v2 공통 규격

- 보행 기본 논리 캔버스 512×512, 긴 무기·옷자락은 768×512. 둘 모두 인물 기준 높이 340, 지면 Y 460.
- 원본 이미지는 보존한다. 런타임 표시 좌표로 정규화하며, PNG 파일 자체가 512×512로 재저장된 것은 아니다.
- 배율 = 340 / (원본 지면 Y − 머리 기준 Y). 발 지지점 중앙을 논리 캔버스 가로 중앙/Y460에 둔다. `asset-layout.js`가 수치의 기준이다.
- 머리 기준점은 장식·상투를 제외한 현재 자세 기준 수동 추정치다. 자세/체격까지 해부학적으로 동일하게 만든 것은 아니며, 후속 자세 제작 시 다시 검토한다.
- v2 비교 캔버스는 모두 같은 768×512 뷰포트에서 렌더링해 넓은 캔버스의 인물이 더 작게 보이는 것을 방지한다.
- 기마병은 말 포함 별도 규격으로 제작하며 지면 기준을 공유한다. 크기는 첫 기마 에셋 제작 때 확정한다. 아직 기마 에셋 없음.
- 고유 인물 스탠딩은 머리/상투, 양팔/손, 허리 아래까지 포함하고 대화용 기본 자세로 제작한다. UI 얼굴은 이 원본에서 표시 영역을 잘라 사용한다. 유비의 기존 가슴 초상화는 이전 버전으로 보존한다.
- 대화 미리보기 문구는 임시이며 시나리오 확정 문구가 아니다.

실제 표시 크기에서 실루엣, 무기, 진영이 구분되는지 확인한다. 생성 이미지의 외곽 여백과 발 위치는 동일하지 않으므로 게임 연결 때 개별 앵커/표시 크기를 지정해야 한다. 이 미리보기의 크기는 검토용이며 최종 배치값이 아니다. 초상화와 전신의 얼굴/복장 세부는 동일성을 검토한 뒤 확정한다.

현재 PNG는 원본 해상도의 검토용 에셋이다. 최종 승인 뒤 표시 크기와 메모리 예산에 맞춰 텍스처를 최적화한다. 별도 공격 프레임, 전장 배경, 이펙트, 실제 게임 UI 교체는 이 묶음에 포함하지 않는다.
