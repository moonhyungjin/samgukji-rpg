# 점진적 아트 제작

2026-10-08 사용자 합의. 생성 횟수와 재작업을 줄이고, 플레이 가능한 구성을 먼저 채운다.

- 기존 유비·보병·황건적·관우·기병 에셋을 기준으로 재사용한다.
- 배치·크기·좌우 반전은 코드로 검토한다. 전체 화면 이미지를 재생성하지 않는다.
- 미제작 장수/병종은 이름과 병종 표식을 유지한다. 다른 장수의 그림으로 대체하지 않는다.
- 신규 제작이 필요하면 기본 자세 한 장의 러프부터. 한 번에 한 가지 문제만 검증한다.
- 얼굴·장비·명암 마감은 실제 게임 크기에서 필요성이 확인된 뒤 진행한다.
- 관우를 포함한 추가 스탠딩/초상화 제작은 대화 화면이 필요해질 때까지 보류한다.
- 고유 스탠딩을 제작할 때는 기존 합의대로 머리부터 허리 아래, 양팔/손을 포함하고 같은 원본에서 UI 초상화를 표시한다.
- 기병 표시 높이 116px는 현재 런타임의 임시 기준이다. 최종 외형/규격 확정을 뜻하지 않는다.
- 프롬프트의 '러프' 표현만으로 도구 비용 감소를 보장하지 않는다. 실제 절감 수단은 생성 횟수 제한, 결과 재사용, 필요한 파일만 읽기다.

다음 순서: 기존 기병의 실제 전투 확인 → 미제작 병종 표식으로 플레이 흐름 확인 → 눈에 띄는 문제부터 하나씩 보완. 새 에셋 대량 생성은 하지 않는다.
