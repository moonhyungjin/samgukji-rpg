# 점진적 아트 제작

## 디자인 담당의 범위와 검증 (2026-10-08 사용자 확정)

- **현재 담당:** 게임 에셋과 UI 디자인. 폰트, 버튼, 카드, 배치, 표시 크기·해상도, 실제 게임 화면의 가독성과 조작을 다룬다.
- **추후 담당:** 전투 애니메이션과 시각 연출. 지금 선행 제작하지 않고 해당 작업 요청이 있을 때 진행한다.
- **기존 게임 데이터를 그대로 사용한다.** 게임 규칙·수치·밸런스, 전투 엔진, Balance Lab의 구현·검증은 개발 담당의 영역이다. 디자인 작업 중 발견해도 직접 수정하거나 재검증하지 않는다.
- 영역 밖 문제가 디자인을 막으면 재현 상황과 필요한 인터페이스/이벤트만 짧게 인계한다. 사용자 요청이 여러 영역에 걸쳐도 디자인 담당 범위를 자동으로 넓히지 않는다.
- **검증은 자신이 바꾼 게임 화면과 에셋에 한정한다.** 관련 화면·조작과 필요한 게임 측 타입/테스트만 확인한다. Lab 검사(`e2e:lab` 포함), 밸런스 시뮬레이션, 저장소 전체 테스트를 디자인 작업의 기본 절차로 실행하지 않는다. 공통 검증 규칙보다 이 역할별 범위를 우선한다.
- 개발 담당이 확인한 내용을 중복 검토하지 않는다. 관련 파일/구간만 읽고, 변경·실패·새 위험이 없으면 통과한 검사를 반복하지 않는다. 문서만 수정한 경우 실행 테스트는 하지 않는다.
- 진행 보고와 인계는 변경 내용·확인 결과·사용자 결정이 필요한 사항만 짧게 적는다. 검토 범위를 늘리기 위해 별도 에이전트를 사용하지 않는다.

현재 슬롯 기준: 전열 1·2·3 / 후열 4·5·6과 빈칸을 항상 유지한다. 아래 제작 이력의 3명 이하 넓은 카드 배치는 폐기됐다. 상세 좌표는 `battle-integration.md`를 따른다.

## 제작 이력

2026-10-09 전략 지도 배치 시안: 설정의 "전략 지도 시안 보기" 또는 `?strategy=1`. `StrategyPreview.tsx`와 `strategy.css`는 기존 `strategyMap`의 지역·위치·인접·세력·성·수입·국력을 표시한다. [기본값: UI 배치] 지도 왼쪽, 지역 정보 오른쪽, 자원 위쪽, 전체 메뉴 아래쪽이며 좁은 화면에서는 정보를 지도 아래에 둔다. 지역 선택과 키보드 조작만 연결했고 전략 상태·자금·행동 결과는 만들지 않는다. 실행 버튼은 비활성, 미연결 수치는 — 표시. 신규 이미지 없이 CSS/SVG로 제작했다. 게임 타입 검사 및 전략 브라우저 검사 8개 통과 (`GAME_E2E_SECTION=strategy`), 캡처 `out/e2e-strategy/`. 엔진·데이터·Lab 수정 및 검사는 없음.

2026-10-08 참고 화면 반영: 행동 커맨드를 카드 위에 겹치는 금색 화살표 이름표로 변경했다. 커맨드의 예상 피해·확률·AP 설명을 숨기고 스킬명만 표시한다. 군단 카드의 병력 게이지를 제거하고 현재/최대 병력을 큰 숫자로 표시한다. 전장과 카드 사이에 진영별 색상의 행동 순서 이름표를 추가했다 (`TurnOrder.tsx`). 현재 행동자를 강조하며 관전에서는 이미 확정된 같은 라운드의 재생 순서를 표시한다.

2026-10-09 캠페인 화면: 설정 화면의 "캠페인 시작 / 이어하기" 또는 `?campaign=1`로 진입한다. `CampaignView.tsx`는 기존 캠페인 API를 사용해 자금, 레벨·경험치·병력/정원/상한, 보충·증원·해고·승급·6칸 편성과 연속 전투 결과를 연결한다. 규칙·수치·Lab은 수정하지 않았다. 정비와 결과의 성공/실패는 엔진 반환값을 표시한다.

저장 [기본값, 사용자 답변 전]: 이 브라우저의 `samgukji-campaign-v1`에 자동 저장한다 (`campaign/progress.ts`). 정비/결과/전투 진입 시 저장하고 결과 재접속으로 보상을 중복 지급하지 않는다. 전투 도중 종료하면 같은 입력과 시드로 전투 처음부터 재개한다. 스키마나 데이터 참조가 맞지 않는 저장은 안내하고 새로 시작 여부를 사용자가 고른다. 브라우저 저장 불가 시 현재 화면에서는 계속 플레이할 수 있지만 저장 실패를 알린다.

행동 순서 연결 완료: 재생은 `roundStart.order`, 수동 대기는 `remainingTurnOrder()`의 확정 순서를 사용한다. 순서를 UI에서 다시 계산하지 않는다. 게임 타입 검사·테스트 63개, 캠페인 브라우저 검사 16개(3연전·패배/재도전·승급·저장/재개·모바일)를 확인했다. 캡처는 `out/e2e-campaign/`.

전투 UI 확인: 브라우저 전투 검사 39개 통과 (`GAME_E2E_SECTION=battle`). 행동 순서 줄은 모바일에서도 전장/카드 경계에 고정한다. 디버프는 카드의 ◆이름·남은 라운드와 틱 피해 숫자·병력을 이벤트대로 갱신한다. 갱신·해제·건너뛰기도 같은 상태를 사용한다. 캡처는 `out/e2e-campaign-battle/`. 엔진·Lab 검사는 하지 않았다.

2026-10-08 어두운 톤 삼국지 UI 윤곽 반영: 사용자 제공 시안(어두운 톤)에 맞춰 화면 윤곽을 고도화했다. 상단 헤더에 양측 진영 현판(`[ 촉 군 ]`, `[ 위 군 ]`, `[ 황건군 ]`), 중앙 `[ N 라운드 ]` 고전풍 현판 및 일체형 사기 바(중앙 사기 배지, 좌우 숫자)를 배치했다. 전장과 하단 UI 경계선(Y=495)에 앤틱 골드 이중 분리 프레임과 중앙 브라켓을 적용하고, 현재 행동자 군단 발밑에 황금색 타원형 지면 링을 추가했다. 유닛 카드에는 흑철/먹색 배경과 엔틱 골드 프레임, 성씨/진영 한자 인장 배지(`劉`, `關`, `張`, `黃` 등), 블록형 황금빛 AP 게이지(`AP ■■■□`), 활성 카드 황금빛 이중 발광 테두리를 적용했다. 중앙 지휘 도크와 카드 액션 메뉴 스타일도 어두운 톤앤매너로 일치시켰다.

카드 메뉴 마무리: 중앙의 이전 스킬/대상 선택 UI를 제거했다. 메뉴에 행동자→대상을 표시하고, 바깥 클릭으로 닫기 및 아래 화살표로 행동 선택·Esc로 카드 포커스 복귀를 지원한다. 전멸 카드도 엔진이 합법 부활 대상으로 반환하면 메뉴를 열 수 있다. 다른 작업에서 추가된 스킬/전투 규칙은 변경하지 않는다.

2026-10-08 조작 변경: 중앙에서 스킬→대상을 고르던 흐름을 카드→가능한 행동 선택으로 바꿨다. 마우스 호버/클릭/터치로 메뉴를 열고 버튼을 눌러 실행한다. 적 공격·아군 지원은 엔진의 합법 대상 목록을 따르며 가드·대기는 행동자 카드에서 선택한다. 중앙은 차례 안내와 AI 위임만 남긴다. 새 에셋은 없다.

UI 카드 2차: 기존 초상화의 표시 크기를 넓은 카드 100px/작은 카드 60px로 조정하고 어두운 금테 프레임을 적용했다. 병력 바, AP 숫자·칸, 가드·결계·버프를 별도 줄로 배치했다. 긴 이름은 카드 안에 맞추며 행동/대상 강조는 금색 직선 테두리를 쓴다. 이미지 생성은 없다.

2026-10-08 UI 배치 1차: 샘플의 먹색·금테 패널과 상단 전장/하단 양측 카드·중앙 명령 구도를 반영했다. 전장 하단 경계는 논리 Y=495(전체 900의 55%). 한 진영이 3명 이하면 430px 카드 한 열, 4~6명이면 기존 200px 카드 두 열이다. 넓은 카드는 열 이동 시 자리 대신 카드의 전열/후열 표시가 바뀐다. 전투 로그는 기본 접힘. 정교한 장식과 초상화 추가는 다음 단계로 남긴다.
