# 첫 전장 아트 연결

## 확인

`npm run game` 실행 후 설정 화면의 **유비 대 황건 보병 · 아트 시험 전투** 링크를 연다.

직접 주소: `http://localhost:5174/?artTrial=1&control=attacker&speed=1&autostart=1`

이 편성은 화면 확인용이며 저장된 기본 편성/장수/병종 데이터를 변경하지 않는다. 기존 전투 엔진과 커맨드/미리보기를 그대로 사용한다.

## 구현

- 상단 평지 전장 + 하단 최대 6대6 카드. 논리 화면은 1280×900.
- 장수 한 명과 공용 병사 세 명이 한 군단을 표현. 병사 수는 장식이며 개별 병사의 판정/HP는 없다.
- 머리/발 좌표를 기준으로 원본 PNG를 배치. 진영 방향이 바뀌면 가로 반전.
- 유비와 황건 보병 A/B에 아트 매핑. 미제작 장수/병종은 이름과 병종 표식으로 표시. 편집기에서 유비를 다른 병종으로 바꾸면 보병 그림을 강제로 쓰지 않는다.
- 카드 및 전장 군단 모두 같은 대상 선택 콜백 사용. 카드와 지면 링의 선택 표시 연동.
- 기본 정지 자세에 짧은 전진/복귀, 피격 점멸/흔들림, 참격, 피해 숫자, 가드/결계 표시 적용.
- 유비의 카드 얼굴은 대화용 스탠딩 텍스처에서 표시 영역을 잘라 사용.
- 에셋 로딩 실패 시 표식/단색 배경으로 대체. Pixi 캐시 텍스처는 화면 재시작 시 파괴하지 않는다.

## 파일

- 실행용 PNG: `apps/game/public/art/battle/` (원본 해상도, 추후 텍스처 용량 최적화)
- 원본 캐릭터 검토용: `docs/art/first-batch/`
- 렌더링: `apps/game/src/render/ArmySprite.ts`, `battleArt.ts`, `UnitSprite.ts`, `BattleScene.ts`
- 배경 프롬프트: `docs/art/plain-background-prompt.json` (내장 image_gen 도구)
- 브라우저 검증 캡처: `out/e2e/art-trial-targets.png`, `art-trial-after-hit.png`

## 다음 범위

관우/기병, 장비/방패병, 궁병 등의 실제 그림, 원거리별 전용 이펙트, 참조 시안과 동일한 중앙 커맨드 UI는 후속 작업이다. 현재 커맨드와 로그는 기존 React 패널에 유지한다. 1차 원본 PNG는 용량이 크므로 대량 콘텐츠 확장 전 해상도/아틀라스 정책을 정한다.
