# 첫 전장 아트 연결

## 확인

`npm run game` 실행 후 설정 화면의 **유비 대 황건 보병 · 아트 시험 전투** 링크를 연다.

직접 주소: `http://localhost:5174/?artTrial=1&control=attacker&speed=1&autostart=1`

이 편성은 화면 확인용이며 저장된 기본 편성/장수/병종 데이터를 변경하지 않는다. 기존 전투 엔진과 커맨드/미리보기를 그대로 사용한다.

## 구현

- 2026-10-08 러프 가독성 보완: 미제작 방패병은 방패 모양 표식으로 구분하고 전장 이름표에 가드 확률/해제 상태와 결계 횟수를 표시한다. 군단 이름표는 그림보다 위의 비상호작용 계층에 두어 기병에 가려지지 않게 한다. 열 이동 시 이름표도 이동하며 격파 시 가드 표시를 숨긴다. 공격 전진 중 이름표는 원래 군단 위치를 유지한다. 새 이미지 생성 없음.

- 상단 평지 전장 + 하단 최대 6대6 카드. 논리 화면은 1280×900.
- 장수 한 명과 공용 병사 세 명이 한 군단을 표현. 병사 수는 장식이며 개별 병사의 판정/HP는 없다.
- 머리/발 좌표를 기준으로 원본 PNG를 배치. 진영 방향이 바뀌면 가로 반전.
- 유비와 황건 보병 A/B에 아트 매핑. 미제작 장수/병종은 이름과 병종 표식으로 표시. 편집기에서 유비를 다른 병종으로 바꾸면 보병 그림을 강제로 쓰지 않는다.
- 카드 및 전장 군단 모두 같은 대상 선택 콜백 사용. 카드와 지면 링의 선택 표시 연동.
- 중앙 지휘 패널은 양쪽 카드 사이에 React UI로 표시한다. 먹색/짙은 녹색 바탕과 금색 선택 상태를 사용하며, 대상 목록에 기존 예상 결과를 유지한다. 내용이 길면 패널 안에서 스크롤한다. 화면 폭 1100px 이하에서는 전장 아래로 내려 카드와 겹치지 않는다. 이 배치는 참조 시안 방향을 따른 1차 구현이며 세부 배치는 검토 대상이다.
- 전투 로그는 전장 아래에 표시한다. 스킬 선택 버튼은 키보드 포커스와 눌림 상태를 제공한다.
- 기본 정지 자세에 짧은 전진/복귀, 피격 점멸/흔들림, 참격, 피해 숫자, 가드/결계 표시 적용.
- 원거리 전용 효과: 궁병/풍수사의 활 공격은 화살, 책략은 절제된 금색 문양, 독연은 옅은 회녹색 연무. 공격자는 제자리에서 발사하며 접촉 후 이벤트의 병력 값을 표시한다. 반격은 기존 근접 연출을 유지한다.
- 유비의 카드 얼굴은 대화용 스탠딩 텍스처에서 표시 영역을 잘라 사용.
- 에셋 로딩 실패 시 표식/단색 배경으로 대체. Pixi 캐시 텍스처는 화면 재시작 시 파괴하지 않는다.

## 파일

이름표 위치는 `ArmySprite.positionAnnotation`에서 관리한다. 전열은 중앙 쪽, 후열은 바깥쪽 여백에 표시하며 화면 경계 안으로 제한한다. 이름표는 클릭을 가로채지 않는다. 동시에 브라우저 검증을 실행하는 경우 `E2E_PORT`와 `E2E_OUT`을 서로 다르게 지정한다.

- 실행용 PNG: `apps/game/public/art/battle/` (원본 해상도, 추후 텍스처 용량 최적화)
- 원본 캐릭터 검토용: `docs/art/first-batch/`
- 렌더링: `apps/game/src/render/ArmySprite.ts`, `battleArt.ts`, `UnitSprite.ts`, `BattleScene.ts`
- 원거리 효과: `apps/game/src/render/rangedEffects.ts`. `action`의 스킬 ID로 외형만 고르고 `damage`의 실제 대상으로 날린다. 가드가 대신 맞으면 가드 군단으로 향한다. 알려지지 않은 스킬은 기존 근접 표현을 유지한다.
- 배경 프롬프트: `docs/art/plain-background-prompt.json` (내장 image_gen 도구)
- 브라우저 검증 캡처: `out/e2e/art-trial-targets.png`, `art-trial-after-hit.png`

## 다음 범위

관우·공용 기병은 116px 임시 기준으로 런타임에 연결되어 있다. 출전한 군단에 필요한 그림만 로드한다. 원본과 크기/방향 비교 페이지는 `docs/art/cavalry/`에 있다. `preview.html`을 파일로 직접 열어 볼 수 있다.

전투 슬롯은 전열 1·2·3 / 후열 4·5·6으로 고정한다 (2026-10-08 사용자 확정). 빈칸을 압축하지 않는다. 논리 화면 1280×900에서 카드 크기는 200×112, 카드 상단 Y는 510/636/762, 전장 군단 기준 Y는 190/286/382다. 인원수에 따른 넓은 카드와 군단 중앙 정렬은 사용하지 않는다. 전열 이동은 같은 줄의 X만 바뀐다. 폰트·버튼·이미지별 제작 해상도 표는 별도 확정이 필요하다.

장비/방패병, 궁병 등 미제작 그림은 임시 표식을 유지한다. `WORKFLOW.md`에 따라 기존 에셋으로 플레이 구성을 확인하고 필요한 부분만 단계적으로 보완한다. 관우 스탠딩/얼굴 카드와 추가 고품질 이미지는 보류한다. 중앙 커맨드 UI와 원거리 효과는 1차 구현했으며 세부 표현은 후속 검토한다. 대량 콘텐츠 확장 전 해상도/아틀라스 정책을 정한다.

2026-10-08 방패/이름표 보완 검증: 타입 검사 통과, 게임 브라우저 검사 37/37 통과. 실제 유관장 대 황건적 캡처는 `out/e2e-shield-labels-final/shu-start-shield-labels.png`. 전체 단위 테스트 실행은 365 통과/4 실패(병력 기대값 2개, 피해 계산기 기대값 2개)였으며 관련 데이터/계산기 코드는 이번 작업에서 변경하지 않았다.

- [확정] 사용자 선택: 책사·도사의 공격은 절제된 문양·기운 효과로 표현한다.
- [기본값] 색과 형태는 구현 해석: 책략은 금색의 작은 원/마름모 문양, 독연은 회녹색 연무. 화살은 얕은 곡선으로 비행한다. 검토 후 조절 가능하다.
- 독연의 연무는 한 번의 공격 연출이며 지속 독·디버프를 뜻하지 않는다. 화계/상태이상은 별도 규칙 확정 후 추가한다.
- 효과는 기존 재생 속도와 즉시/건너뛰기를 따르며 화면 종료 시 정리한다. 판정·피해·AP는 엔진 이벤트가 정한다.
