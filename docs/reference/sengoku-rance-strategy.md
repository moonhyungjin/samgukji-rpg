# 전국란스: 전투 밖 구조 (참고 자료)

> 출처: 사용자가 직접 플레이하며 찍은 스크린샷(한글 패치 화면)과 설명 (2026-10-09). 게임 파일에서 뽑은 것이 아니다.
> 우리 게임의 규칙이 아니라 참고용이다. 우리 게임에 무엇을 가져올지는 설계 문서(04 이후)에서 사용자가 정한다.
> 표기: **[관찰]** 스크린샷에 보이는 것 · **[설명]** 사용자가 말해 준 것 · **[추정]** 에이전트의 해석 (확인 필요)

## 1. 메인 화면 (지도)

| 위치 | 내용 |
|---|---|
| 가운데 | 일본 지도. 지역(국)마다 지배 세력의 문장이 표시된다. 범례: **자국 / 종속국 / 인접국 / 적대국** [관찰] |
| 왼쪽 위 | 고른 지역에서 할 수 있는 **행동 목록**과 필요한 능력치 [관찰] (아래 2장) |
| 왼쪽 가운데 | **行動回数**(이번 턴에 남은 행동 수, 아이콘 개수)와 **턴 종료** [관찰] |
| 오른쪽 위 | **得点**(점수)과 시스템 정보 [관찰] |
| 오른쪽 아래 | 고른 지역의 **국력**, **지배 세력**, 지역 안의 **성(최대 4개)**과 각 성의 소유 세력 [관찰] |
| 아래 막대 | 메뉴 **시스템 / 아이템 / 병력 / 포로**, **코스트 / 국력**, **만족도**, **금**, **턴** [관찰] |

## 2. 지역에서 하는 행동 (한 턴의 행동 수를 쓴다)

스크린샷의 행동 목록 (자국 지역 "이세"를 골랐을 때) [관찰]:

| 행동 | 필요 | 효과 |
|---|---|---|
| 지역 개발 | 건설 9 | 국력 UP |
| 임시 징수 | - | 금을 걷는다 (예: 금 2000 회수 예정) |
| 전투 준비 | 건설 5 | 진행률(%)을 쌓는다 [추정: 다음 전투에 보너스] |
| 인재 등용 | 교섭 6 | 지역의 인물을 설득해 동료로 (예: 법사, 승병) |
| 상점 | ? | 아이템을 산다 |
| 미궁 탐색 | 탐색 5 | 미궁(던전)을 탐색한다 |
| 전군 휴식 | - | 모든 부대가 병력을 조금 회복 (예: 25명) |
| 대만족 보너스 | ? | 만족도 보너스 (10) |
| 이벤트 | - | 이야기 이벤트 (예: [1/7] 진행도) |

- 필요 능력치(건설/교섭/탐색)는 장수의 능력치다. 무장 일람에 **탐/교/건** 열이 있다 [관찰]. [추정] 행동에 참여하는 장수들의 능력치 합이 필요치 이상이어야 한다 (포로 등용과 같은 방식).
- 한 턴에 할 수 있는 행동 수가 정해져 있고(行動回数), 다 쓰면 턴을 끝낸다 [관찰].

## 3. 세력, 국력, 코스트, 만족도, 돈

- **돈(금)**: 수입은 **영지 수에 비례**한다 [설명]. 병력 보충/증원, 상점에 쓴다.
- **국력**: 지역 개발로 오르고 영지를 늘리면 오른다 [관찰/추정]. 아래 막대에 "코스트 10 / 국력 18" [관찰].
- **코스트**: 장수마다 코스트가 있고, **가진 장수들의 코스트 합은 국력을 넘을 수 없다** [설명]. 예: 국력 4일 때 코스트 2 장수가 있으면 코스트 5 장수는 가질 수 없다. 무장 일람에 장수별 코스트 열이 있다 [관찰].
- **만족도**: 성을 차지할수록 오르고, **10점마다 특별 보너스를 하나 고른다** [설명]. 보너스 예 [관찰]: 란스 어택(필살기), 기술 횟수 +1, 전군 휴식 회복량 증가, 아이템, 동료 합류, 보충비 −1, 전군 완전 회복, 병수 제한 +100, 전군 50명 증가, 적대 세력 약화, 전투 준비 효과 증가.
- **캐릭터별 보너스** [관찰]: 장수 하나에 **기능(패시브)**을 붙인다 (공격운, 방어운, 지력운, 속도운, 포박, 상인, 초기 전과, 종료 시 득점, 건강체, 재테크, 반격률 UP 등). **스킬 강화**도 있다 (예: 무사공격 → 무사공격2, 피해 1.1배).
- **점수(得点)**: 오른쪽 위. [추정] 엔딩 평가에 쓰인다 ("종료 시 득점" 기능이 있다).

## 4. 병력 (아래 메뉴 "병력")

- 무장 일람: 병종, **부대 병력(현재/최대, 예: 657/681)**, 행동, 공, 방, 지, 속, 탐, 교, 건, 코스트 [관찰]. 제목에 "무장 일람 [90/127 (비용/국력)]" [관찰].
- 장수 하나를 고르면: 체력, 레벨(예: 42/42), 직종, 장비 아이템, 기능 [관찰].
- 병사 관리: **보충**(1명 금 4), **증원**(1명 금 60, 병종마다 다름), **해고**(1명 금 4 돌려받음), **부대 인원수 상한 500명** [관찰]. 장수마다 정원(최대)이 다르다 [관찰: 681, 1747 등].

## 5. 포로와 등용 (아래 메뉴 "포로")

- 전투에서 잡은 적 장수가 포로가 된다 [설명].
- 등용: 포로마다 **성공 필요치**(예: 13)가 있고, **참가 장수를 골라 그 장수들의 교섭 능력치 합**이 필요치를 넘으면 등용한다 (예: 6 + 4 + 3 = 13, 최대 5명) [관찰/설명].

## 6. 전쟁

- 지역(국) 하나에 **성이 최대 4개** 있다 [설명]. 지역 패널에 성 아이콘과 소유 세력이 보인다 [관찰].
- 전쟁하기 전에 **선전포고**를 한다 [설명]. [추정] 인접한 적대/중립 세력에게만 할 수 있다.
- **지역 안의 성을 모두 차지해야** 그 지역을 얻는다 [설명]. 성 하나가 전투 하나다 [추정].
- [추정] 다른 세력도 내 지역을 공격해 와서 방어전이 생긴다.

## 7. 확인하지 못한 것

- 한 턴의 행동 수와 늘어나는 조건, 출진(성 공격)도 행동 수를 쓰는지
- 출진할 수 있는 장수 수 (전투는 6군단)와 출진한 장수의 병력이 다음 턴까지 이어지는지
- 적 세력의 행동 (공격해 오는 빈도, 선전포고 받는 쪽의 규칙)
- 성마다 수비 부대가 정해져 있는지, 성의 종류(본성/지성)에 따라 다른지
