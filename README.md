# 삼국지 × 전국란스 스타일 전략 RPG — 전투 샌드박스

현재 단계: **Step 0~2 + Balance Lab 완료** (스캐폴딩, 전투 엔진, 시뮬레이터, CLI, Balance Lab UI). PixiJS 전투 화면은 아직 없다.
설계 문서는 `docs/design/`에 있다 (`01-character-and-unit.md`, `02-battle-rules.md`).

## 구조

```text
apps/
  balance-lab/     React + Vite 밸런스 도구 (시뮬레이션은 Web Worker에서 실행)
packages/
  battle-engine/   순수 TypeScript 전투 엔진 (React/PixiJS/DOM 의존 없음)
  game-data/       병종, 특성, 스킬, 캐릭터, 밸런스 수치, 기본 편성
tools/
  sim/             시뮬레이션 CLI
docs/design/       기획 문서
```

`battle-engine`은 데이터를 인자로만 받는다. Balance Lab이 메모리에서 수치를 고쳐 **게임과 같은 엔진**을 돌린다.

## 명령어

```bash
npm install
npm test                 # vitest (엔진, 통합, Lab 로직/렌더링/워커)
npm run typecheck

npm run lab              # Balance Lab 개발 서버 (Vite). 터미널에 나오는 주소(보통 http://localhost:5173)를 연다
npm run lab:build        # Lab 프로덕션 빌드 (apps/balance-lab/dist)

npm run sim -- --iterations 1000 --seed 1 --out out/report.json
npm run sim -- --lineups random                  # fixed | random (병종/캐릭터별 승률은 random에서 본다)
npm run sim -- --balance my-balance.json         # defaultBalance에 부분 덮어쓰기 (Lab의 "밸런스만 내보내기" 파일)
npm run sim -- --target-policy lowest-troops     # highest-damage(기본) | lowest-troops | random
npm run sim -- --team-a shu --team-b wei --roles alternate   # alternate | A-attacks | B-attacks
```

`--balance` 예: `{ "heal": { "scale": 25 }, "morale": { "defenderStart": 52 } }`

## Balance Lab

| 탭 | 기능 |
|---|---|
| 시뮬레이션 | 1 / 100 / 1,000 / 10,000회 실행, 편성(고정/무작위), 공방 배정, 대상 선택 AI, 시드. **수치를 고치면 자동으로 다시 실행**하고 변화량(%p)을 보여 준다. 결과를 기준으로 고정할 수 있다. 목표 지표 점검(경고), 병종/캐릭터/스킬별 통계 |
| 전투 1회 | 고정 편성으로 한 판을 돌리고 라운드별 로그와 최종 상태를 본다 |
| 밸런스 수치 | 피해/치유/병력/반격/사기/스탯 곡선 |
| 병종 · 특성 · 스킬 | 병종 설정(**병력 배율** 포함), 특성 추가/삭제와 병종에 붙이기, 스킬 수치 |
| 캐릭터 | 스탯, AP, 레벨, 병종 |
| 목표 · 가져오기 | 목표 지표 범위(기본: 궁병 생존율 20% ±10%p), JSON 가져오기/내보내기, 초기화 |

- 상태는 브라우저 localStorage에 자동 저장된다.
- **Lab에서 고친 값은 `packages/game-data`의 코드에 자동 반영되지 않는다.** 채택할 값은 "밸런스만 내보내기"(CLI `--balance`로 검증 가능)나 "전체 상태 내보내기"로 꺼내서 옮겨야 한다.
- 화면을 브라우저에서 직접 확인한 것은 아니고, 타입 체크/빌드/개발 서버 응답/서버 렌더링 스모크 테스트/워커 프로토콜 테스트로 검증했다.

## 구현된 규칙

- 라운드제 + AP 총량, 속도순 행동, 동률은 시드 난수로 결정 (재현 가능)
- 커맨드: 일반공격 / 치유 / 대기
- 상호 피해(반격): 근접 일반공격만 반격을 받고 원거리(화살/책략/독연)는 일방적으로 공격
- **상성표 없음, 현재 병종 특성도 없음** (순수 스탯 싸움). 특성 체계는 구현돼 있고 Lab에서 붙여 볼 수 있다
- 병력 비례 피해, 전열 전멸 시 후열이 전열로 이동
- 제로섬 사기: **5:5로 시작, 피해에 영향 없음, 최종 판정에서만 사용** (`maxEffect`를 올리면 피해 보정으로 켤 수 있다)
- 승패: 전멸 군단 수 → 잔여 병력 → 사기 → 방어측, 종료 조건: 전멸 / AP 소진 / 교착 / `maxTurns`
- 진영당 1~6군단 가변 편성, 전열/후열 3+3, 무작위 편성 모드
- 기본 대상 선택 AI: 예상 피해가 큰 적

## 아직 구현하지 않은 것

상태이상(화상/독/젖음), 책략의 날씨/지형 변환, 가드(방패병), 필살기, 승급 병종, AP 회복(풍수사), 아이템, 군단 경험치,
PixiJS 전투 화면. 책략/독연은 현재 피해만 준다.

## 현재 기본 수치의 시뮬레이션 관찰 (무작위 편성 1만 회, 기본 AI)

수치는 모두 임시값이므로 결론이 아니라 **조정 신호**로 본다.

| 지표 | 현재 | 목표 | 비고 |
|---|---|---|---|
| 평균 전투 길이 | 4.3라운드 | 약 5 | 범위(3.5~6.5) 안 |
| 궁병 생존율 | **65%** | 20% | 벗어남 |
| 공격측 승률 | 49.6% | 약 50% | 충족 (사기 5:5·피해 영향 없음으로 해소) |
| 병종 승률 | 보병 **37%**, 기병 **56%**, 풍수사 **59%**, 도사 44% | 45~55% | 보병이 약하고 기병이 강함 |
| 책사/도사/풍수사 생존율 | **19% / 19% / 29%** | - | 방어가 낮아 가장 먼저 노려진다 |

관찰된 구조:

- **보병이 약하다.** 방어가 높아서 "예상 피해" AI가 보병을 피해 후열을 노린다. 전열 방벽 역할(가드, 도발)이 아직 구현돼 있지 않아 보병은 맞아 주는 역할도 못 하고 피해량(평균 584)도 기병(1,103)의 절반이다.
- **기병이 가장 강하다.** 공격이 높고 대상 제한이 없으며(`any`) 스킬 계수가 1.1이다. 특성이 없으니 이를 눌러 줄 요소가 없다.
- **지력 계열이 가장 먼저 쓰러진다.** 물리 공격은 방어로 경감하는데 지력 계열의 방어가 낮다.
- 풍수사 승률이 높다 (치유 약 370/회 > 일반공격). 치유 계수를 낮추면 내려간다 (47 → 25에서 43%였다).
- 사기를 60:40·피해 영향 ±10%에서 5:5·영향 없음으로 바꾸자 공격측 승률이 38% → 49.6%로 돌아왔다.
- **전멸로 끝나는 전투는 거의 없다.** 98%가 AP 소진 후 판정으로 끝나고, 판정은 전멸 군단 수(63%)와 잔여 병력(37%)으로 갈린다. 사기로 갈리는 경우는 0.04%다.
- **1대1로는 서로 못 죽인다.** 관우 vs 하후돈(기병 vs 기병, 병력 1,000): 한 방에 약 290(29%)이지만 반격과 병력 보정 감소 탓에 AP 4를 다 써도 둘 다 살아남고, 먼저 때린 쪽(속도가 높은 하후돈)이 이긴다 (잔여 병력 227 vs 56). 상대가 가만히 맞기만 해도 4번째 공격(AP 전부)에야 쓰러진다.
- 6v6에서는 (기본 AI인 예상 피해 AI에서) 집중 공격이 몰려 첫 군단이 1라운드(50%) 또는 2라운드(48%)에 쓰러지고, 전투당 평균 4.8군단이 쓰러진다.
- **병종별 병력 배율**(`troopScale`): 풍수사 0.5는 지나치다. 승률 61% → 26%, 생존율 거의 0%, 회당 치유량도 줄어든다. 균형점은 0.93~0.95 부근이다.

  | 풍수사 병력 | 승률 (집중 공격 AI) | 승률 (예상 피해 AI) |
  |---|---|---|
  | 1000 (1.0) | 61.1% | 58.6% |
  | 950 (0.95) | 51.1% | 50.1% |
  | 900 (0.9) | 43.3% | 45.3% |
  | 500 (0.5) | 26.5% | 29.0% |

  **집중 공격 AI는 병력 배율과 궁합이 나쁘다.** "현재 병력이 가장 적은 적"을 고르므로 최대 병력이 1이라도 작은 병종은 항상 맨 먼저 노려진다 (배율 1.0 → 0.99에서 풍수사 생존율 89% → 22%). 배율을 실험할 때는 예상 피해 AI가 더 안정적이다.
- 궁병에 "근접에 취약 ×1.3" 특성을 붙이면 생존율이 18%까지 내려간다 (현재는 특성 없이 가기로 했다).
